## 二、`dispersion` 近似常量的机理（接线前置证伪项）

`dispersion = std/|mean|`（千股千评全体评分股的变异系数）。全 A 截面数千样本、评分锚点固定（0-100 轴、≥70 positive / ≤30 negative）→ 截面 CV 由评分分布形状决定，**结构性稳定在 ~0.09-0.10**。观测 45 日 0.087–0.102（极差 0.015）与判据线 0.35 相距 **71%**——该指标在现口径下**不含可触发信息**，不是「还没到 0.35」，是「0.35 这条线在全体评分股 CV 的量纲下物理上不可达」（要到 0.35 需要评分分布出现双峰极端化，历史上极端一致性日也未达）。

## 三、0.0 三义拆态（§1.J 前置条件）

`_compute_sentiment_dispersion` 有 **4 条 return 0.0 路径**：① `em_data` 缺失 ② 列缺失（`综合得分`/`涨跌幅`）③ `len<10` ④ `mean==0`。加上 schema default 0.0（Node 5 整体失败时），`0.0` 现承载三义：**无数据 / 真·高一致 / 缺列**——与「情绪高度一致」不可区分（backlog 判语）。归档时代 0.0 兜底从未实际触发（8 个无值日是字段前时代），但这是数据源没挂过，不是语义没问题。

**拆态方案（建议）**：返回体加 `dispersion_status: enum[ok, insufficient_data, source_missing]`（or `dispersion_available: bool` + 原因码），`dispersion` 仅在 `ok` 时有意义；schema default 改 `None`（Optional[float]）。改动面：`sentiment_analysis.py` :990/:994/:998 三处 return + :224 赋值 + schemas.py :632 + 归档渲染一行。**零决策改动**（无消费者，纯语义卫生）。
