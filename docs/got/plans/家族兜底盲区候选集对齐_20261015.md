## 1. 背景与问题定义

### 1.1 两表定义

| 表名 | 位置 | 用途 | 数量 |
|------|------|------|------|
| **PROMPT_EXPOSED_FAMILIES** | `src/got/family_keywords.py:150-153` | 告知 LLM 的家族白名单（glue prompt 任务2 唯一数据源） | **12 个** |
| **FALLBACK_FAMILIES** | `src/got/family_embed.py:52` | embedding 兜底候选集（FAMILY_KEYWORDS 去 OTHER） | **14 个** |

### 1.2 差集分析

```
FALLBACK_FAMILIES − PROMPT_EXPOSED_FAMILIES = {华为生态, 前沿科技}
PROMPT_EXPOSED_FAMILIES − FALLBACK_FAMILIES = {}（空集）
```

**盲区候选**：**华为生态**、**前沿科技**  
- 只在 FALLBACK 不在 PROMPT
- LLM prompt 永不提及这两个家族
- embedding 兜底却能归属到这两个家族
- **归属不可解释**：规则侧词表能命中 → 不进「其他」→ embedding 不介入；规则侧未命中 → 落「其他」→ embedding 兜底可能判到盲区家族 → 但 glue（LLM）永远产不出这两个家族名

### 1.3 问题本质

**embedding 判得出 glue 永远产不出的家族**（CHANGELOG 2026-10-06 读数发现）。

当某板块落「其他」且 embedding 兜底判定为「华为生态」或「前沿科技」时：
- 规则侧：该板块未被词表命中 → 落「其他」
- embedding 侧：cosine 相似度判定 → 归属「华为生态」/「前沿科技」
- glue 侧（LLM）：prompt 未告知这两个家族 → **不可能产出这两个家族名**

结果：**同一板块在不同路径下归属不一致，且盲区归属无法通过 glue 验证**。

## 4. 推荐与理由

### 4.1 推荐：**选项 A（FALLBACK 收缩到 PROMPT 12 个）**

**理由**：

1. **最保守策略**：
   - 零在线行为变更（embedding 兜底当前 off/shadow，未 enabled）
   - 与 §11.12 裁决一致（「暂不告知 LLM」）
   - 不引入新的 M3 读数口径漂移风险

2. **消除不可解释归属**：
   - prompt 不含的家族，兜底归属不可解释
   - 收缩后 embedding 与 glue 候选集对齐 → 归属一致性提升
   - 「embedding 判得出 glue 永远产不出」的问题消除

3. **改动最小**：
   - 仅 1 行代码改动（family_embed.py:52）
   - 无需改测试（守卫测试仍通过）
   - 无需走 C-P12 replay 验证

4. **「其他」存量略增可接受**：
   - 基于读数，12 次盲区归属消失 → 「其他」从 93/250 略增到 ~105/250（42%）
   - 但「其他」存量随词表演进塌缩（8 月单日到 44，近三周 6~15）→ 实际增量可能更小
   - 且 embedding 兜底当前未 enabled → 实际影响为零

5. **为未来留余地**：
   - 若未来走 replay 验证后决定转正华为生态/前沿科技 → 同时改 PROMPT 和 FALLBACK
   - 当前收缩不影响未来扩展

### 4.2 不推荐选项 B 的理由

1. **在线行为变更**：
   - glue prompt 变更 → LLM 可能产出新家族 → M3 读数口径可能漂移
   - 负责人 2026-10-06 已拍板「必须先走 replay」→ 本轮不应直接转正

2. **关键词冲突**：
   - 华为生态与 AI硬件/智能驾驶直接竞争 → 可能制造新的回收/推翻差异
   - 需 replay 验证 M3 误配率是否上升

3. **违背 §11.12 裁决**：
   - 裁决明确「暂不告知 LLM」→ 本轮不应推翻

### 4.3 不推荐选项 C 的理由

1. **不解决根本问题**：
   - 盲区归属仍存在 → 不可解释性未消除
   - 仅增加 trace 标注 → 治标不治本

2. **增加代码复杂度**：
   - 需增加 trace 逻辑 + 测试
   - 若 enabled 转正，盲区归属仍会直写 → 与 glue 不一致

3. **读数价值有限**：
   - 盲区归属留痕 → 但无法验证准确性（glue 产不出 → 无法对照）
   - 不如直接收缩，消除不可解释归属
