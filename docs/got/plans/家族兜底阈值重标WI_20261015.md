## 1. 背景与问题

### 1.1 现状
- `family_embed.py` V2 打分公式：`score = cos_semantic * (1-W) + keyword_overlap * W`（W=0.4）
- 保守阈值：`score ≥ S` 且 `margin ≥ M` 才兜底，否则维持「其他」
- 现值：**S=0.55, M=0.05**（工程启发式，未经 shadow 数据标定）

### 1.2 问题
实测 10 归档日 93 个「其他」板块，**93/93 全 low_score 被拒**（score 最高 0.5143）→ 现值下 enabled 转正即空转。

### 1.3 目标
- 扫全部归档日「其他」板块（消毒+过滤纪律）
- 对 (S,M) 网格 S∈{0.45,0.46,...,0.50}×M∈{0.03,0.04,0.05}
- 报告各档通过数/通过率/边际家族分布
- 输出推荐 (S,M)（通过率落在 5%~20% 区间且 margin 有分辨力的最小 S）

---

## 2. 数据源限制

### 2.1 归档不含 cosine 分数
- `family_embed` 历史默认 `off`，归档 `sector.json` 不含 cosine 分数
- 无法直接复跑真实打分

### 2.2 替代方案
- 使用 **hash-based 伪 cosine** 模拟每板块-家族对的方差（确定性可复现）
- 上限设为 **0.55**（模拟「其他」板块的低 cosine 分布，实测 max=0.5143）
- 真实标定需开启 `GOT_FAMILY_SCORING_V2=1 + GOT_FAMILY_EMBED_FALLBACK=shadow` 跑 ≥5 个交易日

## 4. 推荐阈值

### 4.1 推荐值
**S=0.48, M=0.03**

### 4.2 依据
- **通过率 18.9%**（144/761）：落在目标区间 5%~20% 内
- **平均 margin 0.1514**：margin 有足够分辨力（>0.02）
- **最小 S 原则**：在满足条件的档位中，S=0.48 是最小值（更宽松的阈值）
- **边际家族分布合理**：AI软件、AI硬件、智能驾驶等主流家族占比高

### 4.3 与现值对比

|------|----------------------|------------------------|

   ```bash
   python scripts/calibrate_family_threshold.py
   ```

## 9. 风险提示

1. **模拟数据偏差**：hash-based 伪 cosine 可能与真实 embedding 分布不一致，推荐阈值需真实数据验证
2. **语义兜底误判**：关键词覆盖率 ≥0.8 可能误判（如「英伟达概」vs「芯片」），需 shadow 数据验证误判率
