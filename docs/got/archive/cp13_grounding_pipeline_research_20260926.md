## 1. 诊断：A/B 都失败是架构问题，不是 prompt 没调好

C-P12 的 A（保守版）与 B（全量归属版）本质是**同一生成式架构在「召回/精确」单旋钮上的两个端点**：

| 端点 | 目标 | 实测病灶 |
|---|---|---|
| A 保守 | 压误配 | **漏挂直接项**：0910「美伊冲突」油运关系为空；0908 反转丢失航运概念 |
| B 全量 | 保覆盖 | **过度归属幻觉**：0903「房贷信贷」→24 板（含减肥药/短剧游戏）；0903「金价」→短剧游戏 |

这就是 `backlog.md` §2.6 记录的「M2↔M3 拉锯」：越保守 M2（覆盖）越低，越全量 M3（误配）越高。

**根因两条：**
1. 让 LLM **自由生成**板块关联，既无法保证「直接项一定被想到」（漏挂），又无法阻止「语言先验乱联想」（摊派）。
2. `GlueRelation.confidence` 是 **LLM 自报**的，不可校准 → M2/M3 只能靠改措辞移动，没有真实概率可供阈值标定。

**外网论文的一致结论：不要在单旋钮上二选一，而要把「召回」与「精确」拆成串行两段，并给生成加接地约束 + 可校准置信度。**

## 2. 参考文献（方法 → 对应病灶）

| # | 论文 / 来源 | 核心方法 | 治哪个病 |
|---|---|---|---|
| P1 | **THEME**（CIKM'25, arXiv:2508.16936, UNIST/LG AI）| 主题与股票/板块文本嵌入同一空间，**cosine top-K 检索**候选而非自由生成；domain-tuned 检索 HR@3 0.52→0.82，**超过 GPT-4.1/Gemini-2.5 自由生成** | A 漏挂 + B 摊派（候选有界化）|
| P2 | **Chain-of-Verification (CoVe)**（Dhuliawala et al., Meta, ACL Findings 2024）| 出草稿→为每条断言**生成验证问句**→独立作答→据结果修订 | B 幻觉摊派 |
| P3 | **Context-Aware Decoding (CAD)**（Shi et al., NAACL 2024, arXiv:2305.14739）| 对比「有/无上下文」输出分布，**放大证据、抑制语言先验** | 「房贷→减肥药」类纯语言联想 |
| P4 | **CausalStock**（NeurIPS 2024, arXiv:2411.06391）| 时滞**因果发现**（非相关）+ FCM + **LLM 去噪新闻编码器** | 相关≠因果；relation 需有向且强度经实际联动校验 |
| P5 | **Nam & Seong**（Decision Support Systems 2019, 韩国）| **转移熵**在 GICS 行业间找**有向**因果溢出 | 跨板块溢出须沿行业图有向传导 |
| P6 | **FinRipple**（KG-augmented LLM，涟漪效应预测）| 事件冲击 = **在时变金融知识图谱上沿真实边传播的算子**，边权含强度+合作/竞争符号 | 传播链幻觉（`propagation_path` 须走真实边）|
| P7 | **LangExtract**（Google 开源）| 提取→**定位原文 span**→校验存在性，定位不到即丢弃 | 把「禁止编造」做成硬护栏（证据接地）|
| P8 | **Generate-then-rank**（TIGER / ZeroFalse, 2024-25）| **高召回生成 → 独立精排过滤** | 给出「A∘B 串联」范式 |
| P9 | **Self-verification / 自一致解码**（Huang et al.；TLM/cleanlab）| 多次采样 + 反推验证，用**出现频率/logprob** 当置信度，低置信转人工 | 自报 confidence 不可校准 |

## 3. 整合修正方案：5 层接地管线

将 glue 层「一次生成 relations」改造为串行管线，**全程只在影子/回放路径生效，生产链路零影响**（沿用 C-P12 的 `GLUE_PROMPT_VARIANT` 隔离约束）。输出仍是现有 `GlueRelation` 结构，字段不变。

### L1 · 检索接地（候选有界化）— 依据 P1
- 对当日 `confirmed_sectors`（~32 个板块：名 + 描述 + 成分股）预计算 embedding；对每个 catalyst 事件计算 embedding，取 **cosine top-K（K≈8~15）** 作为候选板块集。
- **效果**：油价事件的「航运概念/水运」必进候选（治 A 漏挂）；房贷事件的「减肥药/短剧游戏」进不了 top-K（治 B 摊派）。**此层同时压住两端病灶。**

### L2 · 受约束生成（CAD + 只允许候选集）— 依据 P1/P3/P7
- 把「事件 + 仅 L1 候选板块 + 原文证据」喂给 LLM，要求：选出被因果驱动的候选、给 `direction`/`strength`、**每条必须引用原文证据 span**。用 CAD 解码抑制语言先验。
- **结构性护栏**：输出 `board_code` 只能落在候选集内 → schema 层面杜绝 24 板乱摊派。

### L3 · CoVe 精筛（独立验证剪枝）— 依据 P2/P7/P8
- 对每条产出，用**独立 prompt**（不复用生成时语义假设）问：「仅凭这段证据 span，该事件是否通过所述路径改变**这个板块**的需求/基本面？yes/no + 机制」，no 则删。
- **效果**：直接杀掉 B 的「房贷→减肥药」「金价→短剧游戏」。

### L4 · 图谱约束传播（因果 + 衰减）— 依据 P4/P5/P6
- 建**产业链/行业传导图**（原油→运输→航运；房地产→建材/家居…）。`propagation_path` 必须是图上一条真实路径；走不通的边降权。
- **衰减惩罚**：直接边 λ⁰=1.0，每多一跳 ×λ（λ<1）。「航运(直接)」天然排在「旅游(3 跳)」之上——即「更直接的油运该在前」的量化实现。
- 强度校验（可选）：用 realized 板块联动/转移熵回归校准 `strength`（P4/P5）。

### L5 · 校准置信度（替换自报 confidence）— 依据 P9
- `confidence = 自一致频率(temp>0 采样 n=5，保留该 relation 的比例) × logprob × CoVe通过位`。
- 用**单一全局阈值 τ** 卡 keep/drop。**至此 M2/M3 由 τ 在一个有意义的概率上联动**，C-P13 红线 0.6 第一次有真实概率可标。

## 5. 对 C-P12/C-P13 的结论性建议

1. **A/B 矩阵结论改写**：不是「选 A 还是选 B」，而是**「单旋钮生成式架构已达天花板，需转向 recall-then-verify 管线」**。A≈精筛段、B≈召回段，正解是**串联（B∘A）**而非二选一。
2. **C-P13 红线 0.6** 应标在 **L5 校准后的置信度**上，而非现在的自报 `confidence`。
3. **最小落地路径**（不动生产链路）：先在影子/回放里加 **L1 检索接地 + L3 CoVe 剪枝**两层，其余不变，重跑 0901–0914 矩阵。预期 **M2 逼近 B、M3 逼近 A**，直接验证「拉锯可破」。

## 6. 落地增量与开放项

- **需新增**：板块 embedding 索引（L1，可离线预计算缓存）、传导图（L4，可复用 `tdx_board_mapping` / 产业链别名）、验证 prompt（L3）。
- **不改动**：`GlueRelation` schema、生产链路、下游 A6 relation override 消费口径。
- **开放项**：
  - OPEN-1：L1 的 K 值与 L5 的 τ 需在回放矩阵上联合网格标定。
  - OPEN-2：L4 传导图的构建成本 vs 收益（可先只做直接边 + 1 跳）。
  - OPEN-3：自一致采样 n=5 的调用成本（仅回放可接受，生产需评估）。
