# C-P12 prompt A/B 两版文案草案（2026-09-26，待负责人过目）

> **定位**：D-C6 裁决的执行文本。两版只在**一个自由度**上不同——「无把握时的输出策略」
> （保守省略 vs 低置信度保留），其余输入区块、输出 schema、解析校验（S2）、下游消费全部共用，
> 保证 M2×M3 对照曲线测的是 prompt 本身而非混杂变量。
> **依据**：`got_layer_c_plan_0911.md` §5.4 C-P12 / §2.6 C6（M2 红线与 prompt 指令反向、M2↔M3 拉锯）。
> 运行边界：两版**只走 `--got-replay` 影子路径**（`GLUE_PROMPT_VARIANT=a|b` + `GLUE_REPLAY_VARIANT=variant_a|variant_b`），
> 不碰生产默认 prompt（D-C6「拿到曲线前不改默认值」）。落盘按变体目录隔离，互不覆盖。

## 共用部分（两版完全一致，不作变量）

以下区块沿用现行 `_build_glue_prompt`（`aggregator.py:862`），一字不改：

- 输入区：候选板块受控词表（code | name | role | tier | strength_raw）、催化事件（去冗余 4 字段）、
  重大事件、资金流 3d 全量、情绪全局基调、情绪热榜前 50。
- 输出 JSON schema：`strengths[] / families[] / relations[]` 三段的字段形状。
- 任务 2（families）：仅对落「其他」的板块做家族归属，受控词表 12 族 + 「无归属」逃生口。
  **两版不动**——回收率是 M6 口径，不进入本次 A/B 自由度，避免 M6 污染对照。
- 采样参数：temperature=0，max_tokens=16000，单次全量（C1/D9 甲）。

## 版本 A（保守版 ＝ 现行生产 prompt 原文）

任务 1 中（现行口径，逐字保留）：

```
- 没有判据的维度必须写 "unknown"（不要写 "neutral"）
```

任务 3 改为显式化的现行精神（原文「对每条有把握的事件」＋「没把握的事件不要输出（不要编造）」）：

```
### 任务3: relations — 事件→板块归属
只对**有把握**的事件输出归属判断。要求：
- board_code 必须从上方候选列表中选择
- propagation_path 是传导链，每跳是一个实体（公司/产品/技术），终点必须是候选板块
- strength: 事件对该板块的影响强度 (0-1)
- confidence: 你对这个归属判断的置信度 (0-1)
- 没把握的事件不要输出（不要编造）——宁缺毋滥，省略不是错误
- **去重**：每个 (event_id, board_code) 组合只输出 1 条 relation，选最强的传播路径。
  禁止同一事件对同一板块输出多条不同 propagation_path
```

> 注：A 版与现行 prompt 的实质差异仅一条**澄清句**（「省略不是错误」），把 §2.6 实测到的
> Agent 实际行为显式写进指令，消除「指令模糊」这一混杂变量，使 A 成为真正的保守锚点。
> 若负责人要求严格零差异，可去掉澄清句、直接用现行原文跑 A 组（默认建议保留澄清句）。

## 版本 B（全量归属版 · 新文案）

任务 1 改为：

```
- 每个维度都必须给出 high/medium/low 判据，不得留 unknown：
  输入中完全没有该维度证据时写 "low"，并在 evidence 中注明「无直接证据，保守取值」
```

任务 3 改为（D-C6 规格主句 ＋ 三条防跑偏护栏）：

```
### 任务3: relations — 事件→板块归属
**每条有传导链的事件都要给出归属**，不允许整条省略。要求：
- board_code 必须从上方候选列表中选择
- propagation_path 是传导链，每跳是一个实体（公司/产品/技术），终点必须是候选板块
- strength: 事件对该板块的影响强度 (0-1)
- confidence: 你对这个归属判断的置信度 (0-1)
- 把握不足的**用低 confidence（<0.5）表达，不要省略**——省略会让该事件在验收统计中不可见
- **禁止编造**：低 confidence 是指「传导链真实但你不确定其强度/范围」，不是指「可以虚构
  propagation_path」；构造不出「事件→实体→候选板块」真实链条的事件，允许不输出并在
  evidence 类字段中视为放弃（这是 B 版唯一的合法省略通道，放弃量将作为 B 版纪律指标统计）
- **去重**：每个 (event_id, board_code) 组合只输出 1 条 relation，选最强的传播路径。
  禁止同一事件对同一板块输出多条不同 propagation_path
```

> 护栏设计理由：B 版的真实风险不是低覆盖而是**幻觉**（§2.2 陶瓷/建材强行套词表的前车之鉴，
> M3 就是为它设的）。故「全量」定义在「传导链真实存在」前提下，把 M2 的抬升与 M3 的代价
> 同时暴露出来，而不是用「必须全给」逼出编造——那会让曲线两端都失真。

## 判读与运行方案

  M3 人工流程按 OPEN-C2 建议口径执行：每变体每窗分层抽 10 条（低 confidence 5 + 高 confidence 3 +
  随机 2），三档判据（无关系/弱关系/强关系），只有「无关系」计入误配。
  自动侧新增「低置信占比」(<confidence<0.5 的 relation 比例) 作为 M3 代理曲线，人工抽查为终审。
